# References

The implementations are written for this project. These primary materials
provide mathematical background, API documentation and context for further
independent validation.

1. Cox, J. C., Ross, S. A., and Rubinstein, M. (1979). *Option Pricing: A
   Simplified Approach*. Journal of Financial Economics, 7, 229–263.
   [Author paper](https://bpb-us-w2.wpmucdn.com/u.osu.edu/dist/7/36891/files/2017/07/CRR79-1yy8av8.pdf).
2. *Pricing and Hedging Derivative Securities*,
   [The Black–Scholes Formula](https://book.derivative-securities.org/Chapter_BlackScholes.html)
   and [Monte Carlo Methods](https://book.derivative-securities.org/Chapter_MonteCarlo.html).
   Sources for Greeks, discrete hedge accounting, simulation standard errors,
   and antithetic variates.
3. Python documentation:
   [math](https://docs.python.org/3/library/math.html),
   [random](https://docs.python.org/3/library/random.html),
   [statistics](https://docs.python.org/3/library/statistics.html),
   and [unittest](https://docs.python.org/3/library/unittest.html).
4. Streamlit:
   [installation](https://docs.streamlit.io/get-started/installation/command-line)
   and [AppTest](https://docs.streamlit.io/develop/api-reference/app-testing).
5. Matplotlib:
   [documentation](https://matplotlib.org/stable/).
6. GitHub:
   [building and testing Python](https://docs.github.com/en/actions/tutorials/build-and-test-code/python),
   [checkout](https://github.com/actions/checkout), and
   [setup-python](https://github.com/actions/setup-python).
7. [QuantLib](https://www.quantlib.org/), an independent quantitative-finance
   framework suitable for future benchmarking. No QuantLib comparison is
   claimed as completed in this release.
