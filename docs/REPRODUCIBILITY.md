# Reproducing the experiments

## Environment

Run commands from the project root. Create a fresh virtual environment and
install `requirements.txt` for interpreter-compatible dependency resolution.
`requirements-tested.txt` records tested direct versions for Python 3.12:
Matplotlib 3.10.8, pandas 2.2.3 and Streamlit 1.67.0. It is not a transitive
lockfile and should not be used with Python 3.9, where some pinned releases
require a newer interpreter.

`requirements-reference-py312.txt` contains the fully resolved packages from a
fresh Linux/Python 3.12.14 environment. The dashboard CI job uses that reference
lock and interpreter version. It is separate from the portable installation
ranges and is not a cross-platform lockfile.

Record the environment that actually works on your machine:

```bash
python --version
python -m pip freeze > requirements-local.txt
```

Keep that local version record with your run. It is excluded from automatic
version-control staging because a machine-specific environment is distinct from
the cross-version installation requirements. Additional fully resolved locks
for other Python/platform combinations are future work.

## One-command pipeline

```bash
python reproduce.py
```

The pipeline runs the demonstrations, numerical studies, and plots in order.
It rebuilds detailed trials and compact summaries, saves per-command logs, and
writes `results/run_manifest.json` with UTC time, Python/platform information,
direct dependency versions, executed command arguments and SHA-256 digests.

The manifest records files that existed in results at completion, including any
additional protocols run beforehand. It does not imply every older output was
generated by the listed command sequence. Use a fresh copy for a clean reference
run. Numerical equality across arbitrary Python/library versions is not promised;
small floating-point or pseudorandom-normal implementation differences can occur.

`--quick` reduces repeated-estimator studies to 20 repetitions and hedge studies
to 50 paths. It is a setup check, not the reference dataset. Re-run the full
pipeline to restore reference configurations. Existing result filenames are
replaced by the selected run, so copy an output set before changing configuration.

## Dependence and fair comparisons

Within a configuration, different seeds are treated as independent simulation
replications. Across configurations, the same seeded draws or complete stock
paths are reused. Policy outcomes on the same path are paired observations.
Do not pool them as independent observations or interpret overlapping individual
mean intervals as a complete paired significance test.

The antithetic comparison holds total payoff evaluations fixed: 10,000 plain
payoffs versus 5,000 pairs. It does not hold execution time exactly fixed.
Standard errors use 5,000 independent pair averages. A variance factor of two
means half the variance, not half the standard deviation.

Frequency policies share the full 252-interval path. A policy trading every five
observations has a shorter final holding interval because five does not divide
252. Opening and closing stock trades, cash interest and option settlement are
included under every schedule.

## Statistics

Sample standard deviation uses the n-1 denominator. RMSE uses the mean of
squared errors with denominator n. As a result, finite-sample RMSE need not
exceed the displayed sample standard deviation. Mean confidence intervals use
the approximate normal formula mean +/- 1.96*standard_error.

Outcome percentiles use linear interpolation. A 5th-percentile terminal outcome
is not a confidence limit for mean P&L. With 500 paths, tail estimates remain
exploratory. The summary includes separate mean uncertainty estimates.

Monte Carlo normal intervals can be unreliable with small samples or rare
payoffs. Zero observed payoffs can give zero estimated standard error even if
positive rare payoffs remain possible. More independent repetitions, parameter
grids and coverage analysis are appropriate extensions.

## Validation status

The release was checked locally with 71 unit tests and four AppTest UI methods
on Python 3.12.14. Earlier UI checks also passed with Streamlit 1.40.2. The user
reported successful pricing, hedging and research views on a Mac/Python 3.9
environment. GitHub Actions is configured but has not yet run on GitHub.

The suite checks arithmetic and selected invariants over ordinary parameter
ranges. QuantLib benchmarking, broad stress grids, execution-time benchmarking,
and systematic rare-event coverage studies remain future work.
